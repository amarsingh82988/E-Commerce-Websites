# Apne Hath Crafts - E-Commerce Platform

Welcome to the **Apne Hath Crafts** repository. 

This project is a modern, full-stack MERN (MongoDB, Express, React, Node.js) e-commerce application designed for handmade crafts. 

## 📖 Developer Documentation

All developer documentation has been explicitly separated into the respective frontend and backend documentation folders. If you are taking over this project, please begin by reviewing these handover guides:

- 💻 **Frontend Documentation:** [frontend/docs/FRONTEND_HANDOVER.md](./frontend/docs/FRONTEND_HANDOVER.md)
  - Details React, Vite, Tailwind, routing, API layers, and recent UI implementations.

- ⚙️ **Backend Documentation:** [backend/docs/BACKEND_HANDOVER.md](./backend/docs/BACKEND_HANDOVER.md)
  - Details Express, Mongoose, schema optimizations (flattened user schemas), authentication, and order tracking.

- 🔌 **API Reference:** [backend/docs/API_INTEGRATION_REPORT.md](./backend/docs/API_INTEGRATION_REPORT.md)
  - Complete REST API route dictionary.

---

*This architecture has been carefully curated to ensure decoupled database collections, strict TypeScript API contracts, and scalable MERN patterns.*
